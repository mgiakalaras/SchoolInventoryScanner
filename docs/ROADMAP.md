# Roadmap — School Inventory Scanner

## Short term

- Tablet layout test.
- Improve tablet scaling if needed.
- Add splash screen.
- Add first-run mini tutorial/onboarding.
- Add tooltips/help hints for:
  - server setup,
  - folder selection,
  - room selection,
  - QR scan,
  - quick add new item.
- Improve empty/error states.

## Release packaging

- Define stable APK build process.
- Add signed release APK/AAB later.
- Avoid changing many Android files in one patch.
- Keep one feature per commit.

## Later

- Better settings page.
- Better visual polish.
- Optional custom scanner screen if Google Code Scanner limitations become a problem.
- Offline queue only if truly needed.
