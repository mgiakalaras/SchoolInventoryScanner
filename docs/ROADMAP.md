# School Inventory Scanner Roadmap

## Completed by v0.5.0

- Native Android C# scanner foundation.
- Server URL configuration.
- Health check.
- Audit folder list.
- Room list.
- Room session details.
- Google Code Scanner QR scanning.
- Manual QR/code fallback.
- Scan result sync with web app.
- Quick add new item.
- Quick-add options loaded from web API.
- Clear quick-add form sections:
  - item type
  - condition
  - basic details
  - notes
- Android create-room API client.
- Android `+ Νέος χώρος` UI.
- End-to-end first inventory mobile workflow:
  - open first inventory folder
  - create room
  - add item
  - review from web app
- Nullable warning cleanup.

## Candidate v0.6.0

- Better first-inventory UX on Android.
- Room creation hints/templates.
- Recently created rooms/items list.
- Faster switching between rooms.
- Room progress indicators.
- Better tablet layout scaling.
- Optional confirmation before leaving unsaved forms.

## Candidate v0.7.0

- Offline cache foundation.
- Queue unsynced scans.
- Retry failed sync operations.
- More robust error screens.
- Optional device name/source tracking.

## Later

- Full offline first-inventory mode.
- Multi-device audit coordination.
- Login/authentication support when web app adds roles.
- Push/pull sync conflict handling.
- Signed release APK workflow.
