## Body

This release prepares the Android Scanner app for the new **First Inventory / Discovery Mode** workflow of School Inventory Manager.

The Android app can now be used in schools that start their inventory from zero:

- select a first-inventory audit folder
- create rooms directly from the Android device
- open the created room
- add newly discovered items
- sync findings back to the web app for review and QR label printing

### Added

- Android client support for the mobile create-room API.
- `+ Νέος χώρος` UI inside an audit folder.
- Create-room form for first inventory workflows.
- Documentation and release checklist for v0.5.0.

### Improved

- Quick-add item form with clearer structure.
- Safe fallback labels for quick-add guidance/options.
- Nullable warning cleanup.
